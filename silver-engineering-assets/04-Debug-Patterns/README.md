## 核心纪律

看到异常，**先问「数据产生了吗」**，不要先动 UI。
用真实输入调试，不要用 Mock 掩盖（Mock 会隐藏系统问题）。
状态类缺陷优先查：映射表跳变、晚连丢失、多轮崩、reset 不干净。
