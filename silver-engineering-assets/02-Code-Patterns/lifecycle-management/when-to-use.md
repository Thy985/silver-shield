# When to Use · Lifecycle Management

用这个模式，当且仅当——

- [ ] 系统会**重复运行**（循环播放 / 切换输入 / 比赛换组重跑）。
- [ ] 存在**跨帧 / 跨循环累积状态**（追踪、时间窗口、规则计数、决策）。
- [ ] 要求**确定性复现**核心故事（演示不能碰运气）。
- [ ] 需要**不重启进程**就能恢复干净状态（Reset）。

**不要用**，当且仅当——

- 一次性批处理（跑完即退），无状态累积。此时生命周期管理是过度设计。
- 你还没识别「哪些状态需要重置」——先梳理状态清单（见 [../cross-frame-state-aggregation](../cross-frame-state-aggregation/pattern.md)）。

---

## 落地 checklist

- [ ] 区分「模型加载」与「状态初始化」（前者贵、一次；后者可清、多次）
- [ ] `_rebuild_pipeline` 复用 detector，清空跨帧状态
- [ ] Reset 路径复用切换路径，广播事件让前端清空本地累积
- [ ] 测试覆盖：循环 N 轮后风险仍稳定重现；reset 后状态全空
