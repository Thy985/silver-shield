# When to Use · Cross-Frame State Aggregation

用这个模式，当且仅当——

- [ ] 系统是**实时 / 流式**的，单帧数据不足以叙事。
- [ ] 需要跨帧累积出「当前有哪些风险 / 行为如何演化 / 命令是否到位」。
- [ ] 存在**多消费者**共享同一状态（大屏 / 多角色 / 下游服务）。
- [ ] 要求**晚连可恢复历史**、**切换输入不串场**。

**不要用**，当且仅当——

- 纯请求-响应（一问一答），无跨帧状态。此时累积是多余。
- 状态只在单一客户端、从不共享、从不晚连——可留在客户端，不必上移服务端。

---

## 落地 checklist

- [ ] 识别跨帧状态：warnings / commands / behaviors / session
- [ ] 服务端持有聚合状态，客户端退化为快照渲染器
- [ ] 按稳定 key（warning_id）upsert 保活，不逐帧覆盖
- [ ] 终态移除 + 超上限 prune，防无限增长
- [ ] snapshot() 供晚连恢复；clear() 供 reset / 切换源
- [ ] 行为里程碑用去重键跨帧累积
