# AI Pipeline Separation · Architecture

> 文本架构图（可复制为 `architecture.png`，或用 Mermaid 渲染）。

```
                 ┌─────────────────────────────────────────┐
   原始信号 ───▶ │            Perception Layer               │
   (摄像头/文本)  │   检测 + 跟踪 + 多模态编码                │
                 └───────────────────┬─────────────────────┘
                                     │ 带 ID 的检测对象
                 ┌───────────────────▼─────────────────────┐
                 │              Fact Layer                  │
                 │   结构化事实事件（无业务判断）              │
                 │   "谁 / 何时 / 停留多久"                   │
                 └───────────────────┬─────────────────────┘
                                     │ 事实事件
                 ┌───────────────────▼─────────────────────┐
                 │    Feature Layer  │  Rule Layer           │
                 │   数值特征        │  语义 / 风险评分        │
                 └───────────────────┬─────────────────────┘
                                     │ 风险事件
                 ┌───────────────────▼─────────────────────┐
                 │           Decision Layer                 │
                 │   风险语义 → 动作意图（只翻译）            │
                 └───────────────────┬─────────────────────┘
                                     │ 动作指令
                 ┌───────────────────▼─────────────────────┐
                 │      Action Layer（1:1 路由）             │
                 └───────────────────┬─────────────────────┘
                                     │ 指令
                 ┌───────────────────▼─────────────────────┐
                 │   Memory Layer（状态/会话/快照/重置）      │
                 └───────────────────┬─────────────────────┘
                                     │ 投影
                 ┌───────────────────▼─────────────────────┐
                 │        Presentation Layer                │
                 │   人类可读叙事（只读消费核心）              │
                 └─────────────────────────────────────────┘

依赖方向：严格自上而下。
禁止：Fact→Rule 回头读 Fact 之外的业务；Presentation 反向改核心。
```

## Silver Shield 实例对照

```
摄像头 → YOLO/Pose → VisitorEvent → FeatureExtractor → RuleEngine
       → DecisionEngine → Dispatcher → ActionCommand → Dashboard(三视图)
```

各层产物：`VisitorEvent`（事实）/ `WarningEvent`（风险）/ `ActionCommand`（动作）/ `DemoAggregateState`（状态）/ 风险卡+时间线（展示）。
