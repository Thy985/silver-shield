# 银龄盾 Demo · 5 分钟演示剧本（P0-11.5b）

> 目标：在 **5 分钟** 内让评委 / 首看者理解核心价值 ——
> **AI 理解了门口行为 → 风险有可解释的原因 → 风险被发现后产生了人类介入的闭环。**
>
> 本剧本是「演示运行手册」（口播 + 切 Tab 时机 + 点按钮时机全部固定），不是代码。
> 技术底座由 P0-11.5a（稳定 HIGH 闭环）+ P0-11.4（三视图阶段叙事）提供，并经
> `scripts/e2e_validate_demo.py` 真实端到端验证（12/12 通过）确认链路可靠。

---

## 0. 演示前准备（开讲前 2 分钟做完）

1. **启动 Demo（真实视频 + 真实 AI 推理）**
   ```bash
   # system Python 3.14（含 torch CUDA / ultralytics / opencv）
   python scripts/run_demo.py --scenario cctv_surveillance_suspicious
   ```
   - 默认绑定 `127.0.0.1:8765`，仪表盘根路由 `http://127.0.0.1:8765/`。
   - 场景 `cctv_surveillance_suspicious` 已内置 `rule_overrides`
     （`repeat_visit_count: 3→2`）+ `family_contact` 配置 ——
     **保证 HIGH 风险确定性复现**，无需现场调参。
   - 浏览器打开上述地址，**停在 ① 风险发现 标签页**，全屏。

2. **确定性确认（可选，60 秒内）**：观察帧推进，普通访客进出会产生 LOW 预警
   （家属通知）。当同一访客「离开后短时间内再次进入」累积到重复访问 + 多风险规则
   同时命中，① 视图会出现一条 **HIGH 风险**（人话原因：重复访问 / 多风险规则同时命中）。
   - 若开场先不出现 HIGH 也正常：继续讲，它会在视频中段稳定出现。

3. **不要做的事**：不要改 `scenario.fps_target`（设为 0 会让重复访问检测失效、不出 HIGH）；
   不要刷新页面（会重连 WS，但聚合状态仍在，无碍）。

## 3. 演示纪律（别踩坑）

- **切 Tab 不重连 WS**：三个视图共享同一 `DemoAggregateState`，切到 ②/③ 时历史状态已在，
  不丢上下文。可以放心来回切。
- **每个视图只有一个按钮**（方案 A）：②「已确认」、③「完成核验」。不要找第二个按钮——
  设计上刻意避免「三个按钮同效」的穿帮。
- **HIGH 只在 ③ 社区处置 出现**（HIGH→ESCALATE_COMMUNITY→社区单）；LOW 只在 ② 家属确认
  出现（LOW→NOTIFY_FAMILY→家属单）。① 风险发现 显示全部。这是 1:1 路由，不是遗漏。
- **确定性**：`cctv_surveillance_suspicious` 场景已定阈，HIGH 必现。若现场未出现，检查
  是否误改了 `fps_target`（见 §0 注意事项），或重启 `run_demo.py`。
- **时间不够**：优先保 ① HIGH 展示（1:30–2:30）+ ③ 点击闭环（2:30–3:30）这两幕，
  这是「理解→行动」的最小可信闭环。
- **时间一致性**：① 区状态面板的「模拟时间」与 ② 区 AI 行为时间线现已统一到同一时基
  （DemoClock 模拟时间）。桥接层 `frame_result_to_view` 会把 `created_at` 重打为
  `demo_time`（仅作用于 `to_dict()` 副本，不动冻结模型），故两区时间对得上，评委不会看到
  「墙钟时间 vs 模拟时间」错位。

## 4. 验收（与 E2E 对齐）

`scripts/e2e_validate_demo.py` 已对同一条链路做无浏览器端到端断言（12/12）：
网关 assemble → 加载 YOLO → 真实 CCTV 视频帧 → WS 推送 →
**HIGH 产生 + 家属命令(SEND_FAMILY_MESSAGE) + 社区任务(CREATE_COMMUNITY_TASK) +
warning_id 三视图贯通 + 单次点击回写 family_handled / community_done 闭环**。

现场演示是这条已验证链路的「人眼版」：你看到的三幕，就是 E2E 脚本断言的内容。
