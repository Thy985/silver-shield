# 诈骗风险生成模型(Fraud Risk Generation Model)

> —— 从「老人单边假设」到「三方博弈 + DAG 因果图」的升维

---

## 〇、引言:为什么必须升级模型

之前的文档《诈骗成功方程式》存在三个理论缺陷:

1. **概念不严谨**:把模型叫做「成功率」,但成功率无法直接计算或验证。**应该叫「风险指数(Risk Score)」**。
2. **函数形式武断**:直接用 `R = A × B × C × D × E × F`,但「为什么是乘法」没有任何理论依据。**应该诚实表述为「Multiplicative Risk Hypothesis」**。
3. **维度独立假设不成立**:六个维度不是独立的,存在耦合(Trust → Verification),应该是 DAG 因果图,不是平行的乘法。
4. **缺少 Attacker 维度**:只关注老人漏洞,忽略了骗子能力(AI 拟声、DeepFake、社会工程)。
5. **缺少 Guardian 维度**:忽略了第三方干预因素(IRMS 本身)。

本文档 **正式提出诈骗风险生成模型(Fraud Risk Generation Model, FRGM)**,引入三方博弈框架与 DAG 因果建模。

---

## 一、模型升级:从单边模型到三方博弈

### 1.1 传统「老人单边模型」的局限

```
传统模型(原《诈骗成功方程式》):
   Fraud Risk = f(C, P, S, I, V, T)
   只考虑老人侧的 6 维漏洞

局限:
   - 忽略了骗子能力(Attacker Capability)
   - 忽略了第三方干预(Guardian / Defender)
   - 维度独立性假设不成立
```

### 1.2 三方博弈模型:Routine Activity Theory

**Routine Activity Theory(日常活动理论)** 由 Cohen 和 Felson(1979)提出,是犯罪学的经典理论。

> 犯罪成立需要 **三个条件同时满足**:
>
> 1. **Suitable Target(合适的目标)**
> 2. **Motivated Offender(有动机的犯罪者)**
> 3. **Lack of Guardian(缺乏监护人)**

| RAT 三要素 | 在诈骗场景的对应 | 我们的对应模型 |
| --- | --- | --- |
| Suitable Target | 老人漏洞(Vulnerability) | 老人 6 维漏洞模型 |
| Motivated Offender | 骗子能力(Attacker) | 骗子能力维度 |
| Lack of Guardian | 第三方保护缺失 | **银龄盾 IRMS 作为 Guardian** |

### 1.3 整体框架:三方博弈

```
              ┌─────────────────────────────┐
              │  Attacker(骗子)             │
              │  AI拟声 · 话术 · 数据 · 组织 │
              └──────────────┬──────────────┘
                             │ Attack
                             ↓
              ┌─────────────────────────────┐
              │  Vulnerability(老人漏洞)    │
              │  C · P · S · I · V · T      │
              │  (6 维 + 内部耦合 DAG)       │
              └──────────────┬──────────────┘
                             │ Expose
                             ↓
              ┌─────────────────────────────┐
              │  Guardian(监护人)           │
              │  银龄盾 IRMS / Risk OS      │
              │  感知 · 推理 · 调度 · 信任   │
              └──────────────┬──────────────┘
                             │ Defend
                             ↓
              ┌─────────────────────────────┐
              │  Outcome(结果)              │
              │  Risk Score + 干预决策       │
              └─────────────────────────────┘
```

**核心洞察**:
> 诈骗能否成功,不只是「老人有多少漏洞」,而是 **「骗子能力 × 老人漏洞 ÷ 监护人强度」** 的三方博弈。
> **银龄盾 IRMS 在这个框架中的角色,就是 Guardian(监护人)**。

## 二、Attacker Capability(骗子能力)—— 全新维度

### 2.1 为什么必须加入 Attacker 维度

> **诈骗是双方博弈,不是老人单边问题**。
> 同样的老人,遇到不同能力的骗子,被骗概率天差地别。

| 对比 | 低能力骗子 | 高能力骗子(AI 时代) |
| --- | --- | --- |
| 老人(相同) | 60 岁独居,易受骗 0.7 | 60 岁独居,易受骗 0.7 |
| 套路 | 普通电话冒充 | **AI 拟声 + DeepFake + 完整剧本** |
| 成功率 | 30% | **90%+** |

> **老人侧维度无法解释这个差异,必须加入 Attacker 维度**。

### 2.2 借鉴 CVSS(通用漏洞评分系统)

CVSS(Common Vulnerability Scoring System)是网络安全领域的经典评分体系,把攻击者能力分解为多个维度。

**借鉴 CVSS,我们把 Attacker 维度拆为 6 个**:

| 维度 | 含义 | 评分(0-1) |
| --- | --- | --- |
| **A_technique**(技术能力) | 是否使用 AI 拟声 / DeepFake / 伪基站 | 0-1 |
| **A_script**(剧本成熟度) | 是否有完整的诈骗剧本和话术库 | 0-1 |
| **A_data**(数据来源) | 是否掌握老人的个人信息 | 0-1 |
| **A_social**(社会工程) | 是否懂心理操控、压力营造 | 0-1 |
| **A_org**(组织化程度) | 是个人还是团伙(分工协作) | 0-1 |
| **A_resource**(资源投入) | 时间成本、试错次数 | 0-1 |

### 2.3 AI 时代的新增能力

> **2026 年的 Attacker 能力,与 2020 年完全不同**。

| 传统能力 | AI 时代新增 |
| --- | --- |
| 电话冒充 | **AI 拟声**(5 秒样本即可克隆声纹) |
| 文字欺骗 | **DeepFake 视频通话**(实时换脸) |
| 单一剧本 | **LLM 生成个性化话术**(基于个人信息) |
| 人工拨号 | **自动化群呼 + 智能筛选** |
| 单打独斗 | **跨地域团伙协作** |

### 2.4 Attacker Risk Score(参考计算)

```
A_score = f(A_technique, A_script, A_data, A_social, A_org, A_resource)

候选形式(Multiplicative Risk Hypothesis):
A_score = A_technique × A_script × A_data × A_social × A_org × A_resource
```

> **强 Attacker 的特征**:技术 + 剧本 + 数据 + 社会工程 + 组织化 + 资源,六维全高。
> 这种团伙在 2026 年的成功率可以达到 90%+。

## 三、Vulnerability(老人漏洞)—— 6 维分析

### 3.1 6 维结构(沿用)

| 维度 | 含义 |
| --- | --- |
| **C** Cognitive | 认知漏洞 |
| **P** Psychological | 心理状态 |
| **S** Situational | 情境压力 |
| **I** Information | 信息不对称 |
| **V** Verification | 验证成本 |
| **T** Trust | 信任劫持程度 |

### 3.2 函数形式:Multiplicative Risk Hypothesis(诚实表述)

> **诚实声明**:
>
> 我们 **提出** 一个 Multiplicative Risk Hypothesis(乘性风险假设),即:
>
> ```
> V_score = C × P × S × I × V × T
> ```
>
> 这个假设 **不是事实**,而是 **可验证的假设**。
> 它的合理性来自:
> - 任何一维为 0,整体为 0(语义合理)
> - 多维高 → 整体高的非线性放大(现实观察)
>
> 但我们 **不排除其他函数形式**:
> - 加性:`V_score = C + P + S + I + V + T`
> - Logistic:`V_score = σ(α·C + β·P + ...)`
> - Bayesian:`V_score = P(被骗 | C, P, S, I, V, T)`
> - Decision Tree / DNN:`V_score = Tree(C, P, S, I, V, T)`

### 3.3 验证方法

| 数据 | 来源 | 验证 |
| --- | --- | --- |
| 历史被骗案例 | 公安公开数据 | 计算各维度得分,验证 V_score 与实际被骗相关性 |
| 未被骗案例 | 对照组 | 同上 |
| Pearson / Spearman 相关性 | 统计检验 | 验证 V_score 是否显著预测被骗 |
| 模型对比 | ML 模型 | 比较乘法 vs 加法 vs ML 模型的预测能力 |

> **真实工程中,我们倾向用 ML 模型(DNN / XGBoost)替代纯乘法假设**,
> **但保留乘法假设作为「可解释基线」和「业务直觉表达」**。

## 四、6 维之间的耦合 DAG ★ —— 关键理论升级

### 4.1 核心洞察:6 维不是独立的

> 原《诈骗成功方程式》把 6 维当成独立的乘法因子,**但现实中它们存在强耦合**。
> 应该用 **DAG(有向无环图 / 因果图)** 表达。

### 4.2 主要耦合关系

```
Trust(T)
   │
   ▼  ← Trust 劫持后,Verification 几乎被跳过
Verification(V)
   │
   ▼
Information(I)
   │
   ▼  ← 信息不对称暴露认知盲区
Cognition(C)

Situation(S)
   │
   ▼  ← 情境压力激活心理状态
Psychology(P)
   │
   ▼
Fraud Success
```

### 4.3 DAG 详细因果图

```
                        ┌────────────┐
                        │ Attacker A │
                        └─────┬──────┘
                              │ Attack
                              ↓
        ┌──────────────────────────────────────┐
        │ Vulnerability(老人 6 维 + DAG)        │
        │                                      │
        │  Situation(S) ──→ Psychology(P)     │
        │         │              │             │
        │         ↓              ↓             │
        │  Information(I) ──→ Cognition(C)   │
        │         │                           │
        │         ↓                           │
        │  Trust(T) ──→ Verification(V)      │
        │                                      │
        └────────────────┬─────────────────────┘
                         │ Expose
                         ↓
                ┌─────────────────┐
                │ Fraud Success   │
                └─────────────────┘
                         ↑ Defend
                         │
                ┌────────┴────────┐
                │ Guardian G      │
                │ 银龄盾 IRMS     │
                └─────────────────┘
```

### 4.4 三类耦合的解释

#### ① Trust → Verification(因果关系,不是平行)

```
现实案例:
   骗子冒充「儿子」(信任劫持 ↑↑)
      ↓
   老人听到儿子的声音,信任度 100%
      ↓
   老人根本不会验证(verification cost 趋近于 0)
      ↓
   转账被骗

含义:
   T 是 V 的直接因果前置
   不是两个独立维度
```

#### ② Situation → Psychology(情境激活心理)

```
现实案例:
   骗子制造「30 分钟不处理就冻结账户」压力(situation ↑)
      ↓
   老人恐惧心理被激活(psychology ↑)
      ↓
   理性判断被压制

含义:
   S 是 P 的激活器
   不是两个独立维度
```

#### ③ Information → Cognition(信息不对称暴露认知盲区)

```
现实案例:
   骗子知道老人儿子的姓名、工作(information ↑)
      ↓
   老人认知图式中「陌生人知道我信息 = 自己人」的盲区被击穿(cognition 暴露)
      ↓
   老人降低防备

含义:
   I 决定 C 能否被有效利用
```

### 4.5 DAG 模型 vs 乘法模型

| 维度 | 乘法模型 | DAG 因果模型 |
| --- | --- | --- |
| 维度关系 | 平行独立 | 因果耦合 |
| 表达 | R = A × B × C × ... | 图结构 |
| 优势 | 简洁、可解释 | 真实反映因果 |
| 劣势 | 维度独立性假设不成立 | 需要因果推断数据 |
| 适用 | 业务直觉表达 | **风险生成建模** |

> **本文档采用 DAG 模型作为主模型,乘法模型作为业务直觉表达保留**。

## 五、Guardian(监护人)—— 银龄盾 IRMS 在博弈中的角色

### 5.1 为什么 IRMS = Guardian

> **RAT 理论的第三个要素是 Lack of Guardian(缺乏监护人)**。
> **银龄盾 IRMS 的本质,就是「为老人提供 Guardian」**。

```
没有 Guardian:
   Attacker(强) + Vulnerability(高) → 诈骗成功(90%)

有 Guardian(银龄盾 IRMS):
   Attacker(强) + Vulnerability(高) + Guardian(强) → 诈骗失败(10%)
```

### 5.2 Guardian 的能力维度(G_)

| 维度 | 含义 | 银龄盾 IRMS 对应 |
| --- | --- | --- |
| **G_awareness**(察觉力) | 是否能及时发现异常 | Perceive + Understand |
| **G_reasoning**(推理力) | 是否能识别骗局 | Reason + Risk Evolution |
| **G_response**(响应力) | 是否能在老人被骗前拦截 | Resource Scheduling + Action |
| **G_trust**(信任度) | 老人是否愿意接受保护 | Trust Enhancement |
| **G_learning**(进化力) | 是否能持续变强 | Learn 闭环 |
| **G_persistence**(持续性) | 是否能 7×24 在线 | 7×24 主动感知 |

### 5.3 Guardian 介入后的三方博弈

```
                 Attacker
                 A=0.9(强)
                    │
                    │ Attack
                    ↓
              ┌─────────────┐
              │ Vulnerability│
              │ V=0.8(高)   │
              └──────┬──────┘
                     │ Expose
                     ↓
              ┌─────────────┐
              │   Guardian   │
              │   G=0.7(中) │
              └──────┬──────┘
                     │ Defend
                     ↓
              ┌─────────────┐
              │  Outcome    │
              │  Risk Score │
              └─────────────┘
```

### 5.4 Guardian 对 Outcome 的影响

```
引入 Guardian 后:

   Outcome Risk = V × A × (1 - G_effectiveness)

其中:
   G_effectiveness = f(G_awareness, G_reasoning, G_response, G_trust, G_learning, G_persistence)

含义:
   - Guardian 能力越强,outcome risk 越低
   - G_effectiveness 趋近 1,outcome risk 趋近 0
```

## 六、Risk Generation Function:R = f(C, P, S, I, V, T, A, G)

### 6.1 完整函数表达

```
最终模型:

   R = f(C, P, S, I, V, T, A, G)

其中:
   C = Cognitive Vulnerability
   P = Psychological State
   S = Situational Pressure
   I = Information Asymmetry
   V = Verification Cost
   T = Trust Hijacking Degree
   A = Attacker Capability
   G = Guardian Effectiveness

R 是 0-1 的风险指数(Risk Score),而非概率。
```

### 6.2 函数形式:开放问题 ★

> **诚实声明**:函数 f 的具体形式,目前 **没有定论**。
> 我们提出 5 个候选形式,需要实验验证。

| 候选 | 形式 | 优点 | 缺点 |
| --- | --- | --- | --- |
| **Multiplicative Hypothesis** | R = (C×P×S×I×V×T) × A × (1-G) | 简洁、可解释、业务直觉 | 独立性假设 |
| **Additive** | R = αC + βP + ... + λA - μG | 简单 | 抓不住非线性 |
| **Logistic** | R = σ(αC + βP + ... + λA - μG) | 限制在 0-1、平滑 | 系数难定 |
| **Bayesian** | R = P(被骗 \| C, P, S, I, V, T, A, G) | 概率严谨 | 需要先验 |
| **ML Model** | R = DNN(C, P, S, I, V, T, A, G) | 拟合能力强 | 黑盒、需大量数据 |

> **我们的策略**:
> - **业务直觉表达**:用乘法假设,简洁可解释
> - **工程实现**:用 ML 模型(XGBoost / DNN),拟合真实数据
> - **学术诚实**:在论文中明确表述「乘法是假设,不是事实」

### 6.3 当前 MVP 第一版实现

> 由于数据稀疏,第一版采用 **Multiplicative Risk Hypothesis** 作为基线。

```
MVP 公式:
   R = (C × P × S × I × V × T) × A_score × (1 - G_effectiveness)

参数设定(基于专家经验):
   C, P, S, I, V, T, A_score, G_effectiveness 均归一化到 0-1
   当 G_effectiveness > 0.8 时,认为 Guardian 充分介入,R 趋近 0
```

> **第二版扩展**:基于历史被骗数据,用 XGBoost 学习真实函数 f。

| Guardian 维度 | IRMS 模块 | 第一版实现 |

### 7.3 从 DAG 模型看 IRMS 价值

```
DAG 因果链:
   Attacker → Vulnerability → Outcome

   IRMS 的介入:
   Attacker → Vulnerability → [IRMS 介入] → Outcome 显著降低

IRMS 在 DAG 中的位置:
   - 在 Vulnerability 之后、Outcome 之前,作为「拦截节点」
   - 拦截效率 = G_effectiveness = f(G_awareness, ..., G_persistence)
```

## 八、总结:从「单边假设」到「三方博弈」的升维

### 8.1 三个核心升级

| 升级 | 旧模型 | 新模型 |
| --- | --- | --- |
| **概念** | 诈骗成功方程式(成功率) | 诈骗风险生成模型(风险指数) |
| **结构** | 6 维独立 × 乘法 | 6 维 + DAG 耦合 + 三方博弈 |
| **学术态度** | 直接断言乘法 | 诚实表述为「Multiplicative Risk Hypothesis」 |

### 8.2 引入的新维度

| 新维度 | 含义 | 借鉴 |
| --- | --- | --- |
| **Attacker Capability(A)** | 骗子能力 | CVSS(网络安全) |
| **Guardian Effectiveness(G)** | 监护人能力 | Routine Activity Theory(犯罪学) |

### 8.3 核心理论贡献

1. **首次将 Routine Activity Theory 引入反诈场景**
   - RAT 是犯罪学经典,但传统上用于物理犯罪(盗窃、抢劫)
   - 我们创新性地把它应用到 **数字时代的反诈**

2. **首次明确 Attacker Capability 维度**
   - 借鉴 CVSS,把骗子能力分解为 6 个子维度
   - 强调「老人侧模型无法解释高能力骗子的成功率」

3. **首次构建 DAG 因果模型**
   - 把 6 维从「平行独立」升级为「因果耦合」
   - Trust → Verification 等关键因果被显式建模

4. **学术诚实地表述假设**
   - Multiplicative Risk Hypothesis 是「假设」,不是「事实」
   - 多种函数形式被并列讨论,等实验验证

### 8.4 留给未来研究的问题

| 问题 | 现状 | 未来 |
| --- | --- | --- |
| f 的具体形式是什么? | 假设乘法 | 用 XGBoost / DNN 拟合 |
| DAG 的精确权重? | 经验估计 | 用因果推断(do-calculus)学习 |

## 附录 B:数学表达

### B.1 完整模型

```
设:
   C ∈ [0,1]  Cognitive Vulnerability
   P ∈ [0,1]  Psychological State
   S ∈ [0,1]  Situational Pressure
   I ∈ [0,1]  Information Asymmetry
   V ∈ [0,1]  Verification Cost
   T ∈ [0,1]  Trust Hijacking Degree
   A ∈ [0,1]  Attacker Capability
   G ∈ [0,1]  Guardian Effectiveness

DAG 结构:
   T → V (Trust Hijacking 降低 Verification 意愿)
   S → P (Situation 激活 Psychological State)
   I → C (Information Asymmetry 暴露 Cognition)

Risk Generation:
   R = f(C, P, S, I, V, T, A, G)

Multiplicative Risk Hypothesis:
   R_hypo = (C × P × S × I × V × T) × A × (1 - G)

约束:
   当 G → 1,R → 0(Guardian 充分介入)
   当任一维 = 0,R = 0(独立维度为零则风险为零)
```

### B.2 候选函数形式

```
# Form 1: Multiplicative Hypothesis
R1 = (C * P * S * I * V * T) * A * (1 - G)

# Form 2: Additive
R2 = α·C + β·P + γ·S + δ·I + ε·V + ζ·T + η·A - θ·G

# Form 3: Logistic
R3 = σ(α·C + β·P + γ·S + δ·I + ε·V + ζ·T + η·A - θ·G)

# Form 4: Bayesian
R4 = P(被骗 | C, P, S, I, V, T, A, G)

# Form 5: ML Model
R5 = XGBoost(C, P, S, I, V, T, A, G)
```

### B.3 第一版(MVP)实现

```python
def fraud_risk_score(c, p, s, i, v, t, a, g):
    """
    MVP 版本:采用 Multiplicative Risk Hypothesis
    """
    # DAG 修正:Trust 影响 Verification
    v_effective = v * (1 - t * 0.5)  # Trust 劫持后,验证成本实际降低

    # DAG 修正:Situation 激活 Psychology
    p_effective = p + s * 0.3
    p_effective = min(1.0, p_effective)

    # Multiplicative Risk Hypothesis
    v_score = (c * p_effective * s * i * v_effective * t) * a * (1 - g)
    return min(1.0, v_score)
```
