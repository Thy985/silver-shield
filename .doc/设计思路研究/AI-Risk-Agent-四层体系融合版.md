# AI Risk Agent · 四层体系融合版(四人团队终稿)

> **项目定位(答辩开篇可直接复用)**
>
> 我们并不是开发一个简单的防诈骗识别系统,而是构建一个面向居家养老场景的 **AI 风险智能体(AI Risk Agent)**。
>
> 系统以萤石开放平台为感知基础,融合视频、音频、行为和环境等多模态信息,通过 **「感知—理解—预测—推理—评估—资源规划—执行—信任增强—持续学习」** 的完整智能闭环,实现从传统事后报警向 **事前风险预警、智能干预和持续学习** 的升级。
>
> 同时,我们特别关注老年人在深度情感操控下对技术预警的不信任问题,引入 **可解释预警、第三方验证、长期信任建设** 机制,使 AI 不仅能够识别诈骗,更能够让老人 **愿意接受帮助**,真正完成风险防控的最后一公里。
>
> 系统的关键不在于"装了一个 AI",而在于由四个分布式 Agent 协同构成一个完整的端到端防御网络,在家里、家门外、家属身边、社区网格中,同步识别、分级响应。

---

## 一、为什么是「四层体系」而非「功能堆叠」

防诈骗系统最容易踩的坑,是「功能列表越列越长,但评委听完仍然不知道这套东西到底部署在哪里、谁负责哪一块、价值闭环在哪里」。

我们认为,一个真正完整的防诈骗项目,必须回答 **四个不同层面的问题**:

| 层面 | 回答的问题 | 谁来回答 |
| --- | --- | --- |
| **Where(系统层)** | 系统部署在哪里?如何延伸到老人生活的全部空间? | **第三位队友** |
| **What(功能层)** | 系统能识别哪些诈骗场景?覆盖哪些业务? | **第一位队友** |
| **How(智能层)** | AI 如何思考、推理、决策、调度资源? | **本人(智能层)** |
| **Human(交互层)** | AI 如何让老人真正愿意接受帮助? | **第二位队友** |

**四层堆叠,缺一不可**:
- 没有 **Where**,AI 只看得到家里,老人一出门就失明。
- 没有 **What**,再聪明的 AI 也不知道自己要解决什么业务问题。
- 没有 **How**,系统只是「摄像头 + App」,没有真正的智能。
- 没有 **Human**,AI 判断再准,老人不信也无效。

这就是我们 **四人团队** 必须融合成一个 AI Risk Agent 的原因 —— 不是分工拼凑,而是 **每层都不可或缺**。

## 二、四层体系总览

```
                    ┌─────────────────────────────────────┐
                    │      Human(交互层)                  │
                    │      Trust Layer                     │
                    │   可解释 · 第三方验证 · 长期信任      │
                    │   · 认知缓冲 · 事后复盘              │
                    │        [第二位队友]                  │
                    └─────────────────────────────────────┘
                                       ↑
                    ┌─────────────────────────────────────┐
                    │      How(智能层)                    │
                    │      AI Risk Agent                   │
                    │  Perceive → Understand → Predict    │
                    │  → Reason → Evaluate → Plan         │
                    │  → Act → Trust → Learn              │
                    │        [本人 · 智能层]               │
                    └─────────────────────────────────────┘
                                       ↑
                    ┌─────────────────────────────────────┐
                    │      What(功能层)                   │
                    │      诈骗场景识别                     │
                    │   电话诈骗 · 入户诈骗 · 会销诈骗     │

                    │        [第一位队友]                  │
                    └─────────────────────────────────────┘
                                       ↑
                    ┌─────────────────────────────────────┐
                    │      Where(系统层)                  │
                    │      产品部署架构                     │
                    │   Home + Mobile + Family + Community │
                    │        [第三位队友]                  │
                    └─────────────────────────────────────┘
```

**一句话讲清四层关系**:
> **Where(部署在哪里)承载 What(识别什么场景),通过 How(如何智能决策),最终实现 Human(如何让人接受)**。

## 三、第三位队友的贡献:系统边界与场景架构

> 这一层 **最容易被低估**,但也是 **最容易被评委追问的**。
> 评委一定会问:「你这个系统到底部署在哪?老人的所有生活场景都能覆盖吗?」
> 没有系统层,你答不上来。

### 3.1 第一层贡献:产品形态(Product Form)

把 AI Risk Agent 的「眼睛」部署到老人生活的 **全部关键节点**:

| 端 | 设备形态 | 覆盖场景 | 角色定位 |
| --- | --- | --- | --- |
| **Home** | 萤石摄像头、门铃、门磁、拾音器 | 客厅、门口、卧室 | **AI 的眼睛**(Home Edge) |
| **Mobile** | 老人手机 | 外出、讲座、会销、广场 | **AI 的延伸**(让 AI 走出家门) |
| **Family** | 家属 App / 微信小程序 | 远程查看、远程决策、远程视频 | **AI 的决策臂**(家属介入) |
| **Community** | 社区网格员平台 / 物业 | 线下确认、上门拦截 | **AI 的执行臂**(本地兜底) |

**关键洞察**:

> 老人有两个世界 —— **家里** 和 **Outside**。
> 多数项目只覆盖家里,所以老人一出门就失明。
> 老人手机补足了「家门外」这一段,让 AI Risk Agent **不是 4 个独立端,而是一个连续覆盖的网络**。

### 3.2 第二层贡献:场景闭环(Scene Coverage)

> 很多方案只覆盖 **「被骗 → 报警」**,我们覆盖的是 **整个诈骗生命周期**。

**诈骗生命周期**:

```
接触          建立信任        持续影响        诱导交易         付款
 ↓              ↓              ↓              ↓              ↓
陌生号码      "关心你健康"    频繁联系        "稳赚项目"      转账
陌生人上门    "免费体检"      赠送小礼品      "名额有限"      交现金
AI 拟声       "我是你儿子"    情感操控        "保密"          抵押
```

**每一段生命周期,都对应 AI Risk Agent 的不同响应**:

| 阶段 | 信号 | AI 介入层 | 响应动作 |
| --- | --- | --- | --- |
| **接触** | 陌生号码、陌生人上门 | Perceive + Understand | 标签化(异地/高频/未登记) |
| **建立信任** | 频繁联系、关心话术、免费物品 | Predict | 趋势预测:风险上升 |
| **持续影响** | 行为偏离、情绪异常 | Reason | 综合推理,关联历史 |
| **诱导交易** | 关键词(投资/养老/保密) | Evaluate | 高风险 + 可解释 |
| **付款** | 准备出门、银行 App | Plan + Act | **最优资源调度 + 多通道干预** |

> 这就是 **Customer Journey(用户旅程)** 在防诈骗场景的应用 —— 不是「事件驱动」,而是「生命周期驱动」。

### 3.3 第三层贡献:多端协同(Multi-Endpoint Collaboration)

> 多数 AI 系统是 **「集中式」** —— 一个大脑,所有摄像头往这一个大脑送。
> 我们的设计是 **「分布式 Agent」** —— 每个端都是一个独立 Agent,各自能感知、能决策、能执行。

| 端 | Agent 名字 | 核心能力 |
| --- | --- | --- |
| **Home** | **Home Agent** | 视觉/听觉感知(陌生人识别、情绪识别、关键词) |
| **Mobile** | **Mobile Agent** | 通信感知(通话、短信、App 安装、浏览器) |
| **Family** | **Family Agent** | 决策与干预(远程视频、紧急暂停、证据转发) |
| **Community** | **Community Agent** | 线下执行(上门确认、网格员介入、警方联动) |
| **Center** | **AI Risk Agent** | 统一调度(综合推理、资源规划、跨端协同) |

**关系图**:

```
                      AI Risk Agent(统一调度)
                              ↓
        ┌────────────┬───────────┬────────────┬────────────┐
        ↓            ↓           ↓            ↓
   Home Agent   Mobile Agent  Family Agent Community Agent
   (萤石)      (老人手机)    (家属)        (社区/物业)
```

**这是真正的分布式智能**:
- 摄像头 = 发现
- 手机 = 确认
- 家属 = 决策
- 社区 = 执行
- AI Risk Agent = 调度

### 3.4 第四层贡献:空间维度(Spatial Dimension)

> 多数项目只看到一个空间:家。
> 我们看到两个空间:家里 + 家门外。

| 空间 | 风险类型 | 感知来源 |
| --- | --- | --- |
| **家里** | 陌生人上门、推销、保健品送货、情绪异常 | 萤石摄像头、门铃、拾音器 |
| **家门外** | 会销、养老讲座、免费鸡蛋、广场活动、AI 拟声电话 | 老人手机、通话监听、App 分析 |

> 没有 Mobile Agent,系统就只是一个 **「室内摄像头套件」**,不是防诈骗系统。

### 3.5 第五层贡献:产品部署架构图

```
                     ┌──────────────────┐
                     │   Community      │
                     │  (社区/物业)      │
                     └────────┬─────────┘
                              ↑
                              │
   ┌──────────────┐    ┌──────┴───────────┐    ┌──────────────┐
   │   Family     │ ←  │   AI Center      │ →  │  Elder Phone │
   │   (家属端)   │    │ (AI Risk Agent) │    │  (Mobile)    │
   └──────────────┘    └──────┬───────────┘    └──────────────┘
                              ↑
                              │
                     ┌────────┴─────────┐
                     │  Hikvision Camera │
                     │  (Home Edge)     │
                     └──────────────────┘
```

**不是「一个 App」,而是「一个完整的端到端防御网络」**。

## 四、四 Agent 分布式架构详解

### 4.1 Home Agent(家庭端 Agent)

**载体**:萤石摄像头、门铃、门磁、拾音器
**核心能力**:
- 视觉感知:陌生人识别、行为识别、表情/情绪识别
- 听觉感知:关键词提取(投资/养老/保密/转账)、AI 拟声检测
- 触发条件:有人按门铃、检测到陌生人、检测到异常情绪

**典型动作**(自治执行,不依赖中央):
- 门铃被按 → 自动拍照 → 推送家属
- 检测到「投资」关键词 → 立即触发本地录音保存
- 检测到陌生人 + 老人对话紧张 → 自动标记事件

### 4.2 Mobile Agent(老人移动端 Agent)

**载体**:老人手机(权限允许范围内)
**核心能力**:
- 通信感知:陌生号码、异地号码、高频来电
- App 感知:安装未知 App、可疑浏览器访问
- 短信感知:钓鱼短信、可疑链接
- GPS 感知:非常去地点(酒店、会销高发地)

**典型动作**:
- 检测到 5 个陌生号码连续呼入 → 实时通知家属
- 检测到异地号码 + 通话 > 30 分钟 → 自动录音
- 检测到老人进入会销高发地点 → 推送提醒 + 实时定位给家属

### 4.3 Family Agent(家属端 Agent)

**载体**:家属 App / 微信小程序
**核心能力**:
- 远程查看:实时视频、历史录像、风险事件
- 远程决策:确认/否认/升级
- 远程干预:视频通话、紧急暂停、一键报警
- 反馈闭环:误报标记、模式修正、画像更新

**典型动作**:
- 收到高风险预警 → 一键发起视频通话
- 确认是诈骗 → 触发 Plan 层的资源调度
- 确认是误报 → 触发 Learn 层的模式降权

### 4.4 Community Agent(社区端 Agent)

**载体**:社区网格员平台、物业系统、派出所联动
**核心能力**:
- 线下兜底:当家属/邻居无响应,社区介入
- 持续关注:对高风险老人做长期跟踪
- 应急流程:对已发生诈骗快速响应(冻结账户、心理疏导)
- 群体保护:同一社区出现相似模式,群体预警

**典型动作**:
- 收到家属无响应 + 老人风险持续升高 → 网格员上门
- 同一栋楼出现 3 起类似陌生拜访 → 群体预警其他老人
- 老人已转账 → 自动对接派出所 + 反诈中心

### 4.5 AI Risk Agent(中央调度 Agent)

**载体**:云端 AI 中心
**核心能力**:
- 综合推理:跨端信号融合 + 因果链推理
- 风险评估:可解释评分 + 风险来源占比
- 资源规划:动态选择最优介入资源 + 顺序
- 跨端协同:同时调度 Home/Mobile/Family/Community 协同响应
- 持续学习:个人画像 + 全局规则迭代

**与四 Agent 的关系**:
- **不是替代,而是调度** —— 四个端 Agent 各自能自治,中央负责协同。
- **不是中心化黑盒** —— 即使中央 Agent 临时不可用,各端 Agent 仍能本地应急。

## 五、四层堆叠详解

### 第一层:Where(系统层)—— 部署在哪里

> 由第三位队友主导。

**核心问题**:系统部署在哪?如何延伸到老人生活的全部空间?

**核心要素**:

```
┌───────────────────────────────────────────────┐
│ Where                                         │
│                                               │
│  Home Edge(萤石) ─┐                           │
│                    │                           │
│  Mobile(手机) ────┼─→ AI Center ─┬─ Family    │
│                    │              │            │
│  Community ───────┘              └─ 调度闭环   │
│                                               │
│  空间维度:家里 + 家门外                        │
│  时间维度:接触 → 建立信任 → 持续 → 诱导 → 付款 │
└───────────────────────────────────────────────┘
```

**为什么重要**:
- 没有 Where,系统只是「一个 App」,不能形成端到端防御。
- 没有 Where,AI 再聪明也只能看到家里 —— 老人一出门就失明。

---

### 第二层:What(功能层)—— 识别什么场景

> 由第一位队友主导。

**核心问题**:系统能识别哪些诈骗场景?

**诈骗场景分类**:

| 场景 | 信号 | 接入端 |
| --- | --- | --- |
| **电话诈骗** | 陌生号码、异地、关键词 | Mobile Agent |
| **入户诈骗** | 陌生人上门、宣传资料、情绪紧张 | Home Agent |
| **会销/讲座诈骗** | 异地 GPS、频繁外出、行为偏离 | Mobile Agent |
| **AI 拟声诈骗** | 声纹异常、AI 生成语音特征 | Mobile / Home Agent |
| **情感操控** | 持续联系、保密要求、转账关键词 | Home + Mobile |
| **网络钓鱼** | 短信链接、可疑 App、可疑浏览器 | Mobile Agent |
| **冒充公检法** | 关键词(公安/法院/安全账户) | Home + Mobile |
| **冒充亲友** | 声纹异常、AI 拟声、关键词 | Mobile Agent |

**与第一层 Where 的关系**:
- 不同的诈骗场景,**发生在不同的空间**。
- 电话诈骗 → Mobile;入户诈骗 → Home;会销 → Mobile(外出);AI 拟声 → Mobile + Home。
- **没有 Where,What 就失去了部署锚点**。

---

### 第三层:How(智能层)—— 如何智能决策

> 由本人(智能层)主导。这是 AI Risk Agent 的核心。

**核心问题**:AI 如何思考、推理、决策、调度资源?

**九层架构**:

```
Perceive(感知)
    ↓
Understand(理解)
    ↓
Predict(预测)
    ↓
Reason(推理)
    ↓
Evaluate(风险评估)
    ↓
Plan(资源规划)
    ↓
Act(执行干预)
    ↓
Trust(信任增强)        ← 与 How 并列,作为第四层 Human 的入口
    ↓
Learn(持续学习)
    ↓ → 回到 Perceive(闭环)
```

**与第一/二层的对接**:

```
Where(Home/Mobile/Family/Community 端) → 原始信号
       ↓
What(场景分类与多模态标签) → 结构化标签
       ↓
How(AI Risk Agent 九层) → 风险评估 + 资源调度
       ↓
Human(Trust Layer) → 让老人愿意接受
       ↓
Act 回到 Where 各端 → 真正执行
```

#### 5.1 Perceive(感知)

**目标**:世界发生了什么?
**铁律**:只采集事实,不下结论。

| 模态 | 来源(对应 Where) | 采集内容 |
| --- | --- | --- |
| 视频 | Home Agent(萤石) | 陌生人、访客停留、老人动作 |
| 音频 | Home Agent(拾音器) | 环境对话、关键词、AI 拟声检测 |
| 通信 | Mobile Agent | 陌生号码、未知 App、短信、浏览器 |
| 环境 | Mobile + Home | 时间、地点、是否独居、是否夜间 |

**输出示例**:
```json
{ "time": "09:32", "event": "陌生号码呼入", "duration": 38 }
{ "time": "10:15", "event": "陌生男子进入", "stay": 42 }
```

#### 5.2 Understand(理解)

**目标**:这些事实意味着什么?
**职责**:把事实标签化、结构化。

```json
{
  "call":   { "carrier": "unknown", "history": "first_contact", "region": "高频骚扰地" },
  "visitor":{ "registered": false, "carry": ["宣传资料"], "frequency": "3天连续" },
  "speech": { "keywords": ["安全账户", "保密", "投资", "养老金"] }
}
```

#### 5.3 Predict(预测)

**目标**:未来是否存在风险?
**关键**:不是「有没有被骗」,而是预测「未来」。

- 趋势预测:最近每天接十几个陌生电话 → 正在被围猎
- 关系预测:陌生人连续一周上门 → 正在建立信任
- 行为预测:老人频繁去保健品讲座 → 未来风险增加

#### 5.4 Reason(推理)

**目标**:综合因果链,给出 **可解释** 结论。

```
Q: 为什么风险 90?
A: 因为同时满足
   ① 陌生号码(异地)
   ② 40 分钟电话
   ③ 涉及「投资」「养老金」关键词
   ④ 陌生人拜访(连续 3 天)
   ⑤ 老人近期行为异常
   ⑥ 老人独居
```

#### 5.5 Evaluate(风险评估)

**目标**:风险有多大?为什么?

```json
{
  "score": 92,
  "level": "极高",
  "type": "投资诈骗",
  "urgency": "30min",
  "breakdown": {
    "投资诈骗": 55, "陌生人": 25, "行为异常": 20
  },
  "confidence": 0.92,
  "explanation": "陌生异地号码引导投资 + 频繁外出行为偏离 + 独居无人即时干预"
}
```

#### 5.6 Plan(资源规划)

**目标**:谁最适合介入?按什么顺序?

| 场景 | 资源选择 | 原因 |
| --- | --- | --- |
| 家属就在附近 | 家属(一级) | 信任度最高、响应最快 |
| 家属在国外 | 社区(一级) + 邻居(二级) | 家属远水难救近火 |
| 老人正在转账 | 警方(直接介入) | 资金紧急 |
| 陌生人敲门 | 门铃语音提醒 | 不升级打扰 |
| 跌倒/生命危险 | 邻居 + 120 | 比家属到场更快 |

**输出示例**:
```json
{
  "primary":   { "resource": "邻居-王阿姨", "ETA": "3min",  "action": "上门确认" },
  "secondary": { "resource": "家属-女儿",   "ETA": "12min", "action": "远程视频确认" },
  "tertiary":  { "resource": "社区网格员",  "ETA": "30min", "action": "待命,前两级无响应则升级" },
  "fallback":  { "resource": "派出所",      "ETA": "45min", "action": "转账行为触发" }
}
```

#### 5.7 Act(执行干预)

**目标**:把 Plan 的指令真正落到现实。

| 通道 | 对象 | 典型内容 |
| --- | --- | --- |
| 本地语音 | 老人 | "爸,请暂停操作,您的女儿正在视频确认" |
| 微信/App | 家属 | "诈骗风险 92%,建议立即视频确认" |

| 社区平台 | 网格员 | "老人疑似被围猎,需要上门确认" |
| 录像/证据 | 事后追溯 | 保存关键片段 |

#### 5.9 Learn(持续学习)

**目标**:让系统越来越懂这位老人。

**反馈通道**:
1. 家属反馈:「其实是装修」→ 模式降权
2. 误报修正:同一模式多次被否 → 权重下降

5. 规则迭代:风险评分公式、阈值、Plan 顺序都被迭代

### 第四层:Human(交互层)—— 如何让人接受

> 由第二位队友主导。

**核心问题**:AI 如何让老人 **真正愿意接受帮助**?

**为什么必须单列一层**:
> 防诈骗真正难的不是识别,而是 **让老人相信**。
> 老人被骗的核心是 **深度情感操控**,他们对「陌生人」反而建立了信任,对「AI 提醒」反而抗拒。

**Trust 五层机制**:

#### ① 可解释预警(Explainable Warning)

```
不是:  "危险"
而是:  "检测依据:陌生号码 + 要求转账 + 持续 40 分钟,风险 92%"
```

**为什么有效**:把判断过程「让渡」给老人,信任度立刻上升。

#### ② 认知缓冲(Cognitive Buffer)

```
不是:  "你被骗了"
而是:  "建议您先暂停 5 分钟,系统正在联系您的女儿确认"
```

**为什么有效**:正面对抗会触发防御心理,「暂停 5 分钟」是可接受的微小动作,为真正干预争取时间。

#### ③ 第三方验证(Third-Party Verification)

```
不是:  "AI 说:这是诈骗"
而是:  "已联系:女儿。她说:妈,千万别转,我 10 分钟到"
```

**为什么有效**:被骗的老人对 AI 天然不信任,但 **对家人极度信任**。三段式传递,把 AI 判断转译成老人愿意相信的语言。

#### ④ 长期信任建设(Long-term Bonding)

```
每天:  天气提醒、吃药提醒、喝水提醒、睡眠报告
形式:  像家人,而非像机器
```

**为什么有效**:信任是 365 天攒出来的,危机时刻才有分量。

#### ⑤ 事后复盘(Post-incident Review)

```
事件:  骗子冒充公安,要求保密、要求转账
复盘:  帮助老人识别「冒充公检法」的套路
成长:  下次再遇到,老人能自己识别 70% 的类似话术
```

**为什么有效**:把一次伤害转化为长期免疫力,同时修复老人被诈骗损伤的自我价值感。

**Trust 与 Act 的关系**:

| 层 | 职责 | 类比 |
| --- | --- | --- |
| Act | 把决策 **执行出去** | 战术动作 |
| Trust | 让决策 **被接受** | 战略能力 |

> 没有 Trust 的 Act:发了一百条提醒,老人全部忽略。
> 有 Trust 的 Act:一句话,老人立刻停下转账操作。

## 八、答辩统一表述(可直接复用)

> 我们并不是开发一个简单的防诈骗识别系统,而是构建一个面向居家养老场景的 **AI 风险智能体(AI Risk Agent)**。
>
> 系统以萤石开放平台为感知基础,融合视频、音频、行为和环境等多模态信息,通过 **「感知—理解—预测—推理—评估—资源规划—执行—信任增强—持续学习」** 的完整智能闭环,实现从传统事后报警向 **事前风险预警、智能干预和持续学习** 的升级。
>
> 同时,我们特别关注老年人在深度情感操控下对技术预警的不信任问题,引入 **可解释预警、第三方验证、长期信任建设** 机制,使 AI 不仅能够识别诈骗,更能够让老人 **愿意接受帮助**,真正完成风险防控的最后一公里。
>
> 系统的关键不在于"装了一个 AI",而在于由 **四个分布式 Agent**(Home / Mobile / Family / Community)协同构成一个完整的端到端防御网络,在家里、家门外、家属身边、社区网格中,**同步识别、分级响应**。我们的四位团队成员,分别回答了 **Where(部署在哪里)、What(识别什么)、How(如何决策)、Human(如何让人接受)** 四个不同层面的问题,缺一不可,共同构成一个统一的 AI Risk Agent。
